# 03 品牌与对外信息口径 (Brand Messaging)

## 20 个独立站的品牌分化与话术口径
耐科独立站站群绝不是复制站，每个站点前台必须拥有鲜明独特的商业角色：
1. **econaike.com**: “企业旗舰信任港” —— 聚焦大厂制造实力、审厂资格、全品类入口与 ESG 绿色智造。
2. **eazylunch.com**: “儿童便当盒创新标杆” —— 聚焦母婴级安全、极度防漏、人体工学分格与抗摔耐用。
3. **sustainabletablewarefactory.com**: “可持续材料工程专家” —— 聚焦生物基材料选型、LCA 成本比较与低碳转型方案。
4. **siliconebabyfeedingset.com**: “高端铂金硅胶母婴工坊” —— 聚焦 100% 铂金硫化、10kg 吸盘物理学与莫兰迪高级色彩。
5. **outdoortablewarefactory.com**: “极致轻量化露营餐具站” —— 聚焦嵌套收纳、-20°C 耐寒抗摔与便携网袋套装。
6. **privatelabeltableware.com**: “DTC 与亚马逊私牌孵化器” —— 聚焦 500 套小单快反、精美开箱包装与 3D 渲染图包。
7. **retailreadytableware.com**: “跨国商超直供与拼柜管家” —— 聚焦 PDQ 零售托盘展示盒、GS1 条码合规与 40HQ 满载集运。

## 反洗绿准则 (Anti-Greenwashing Policy)
为确保在欧洲和北美市场不被监管罚款或买家索赔，严格执行 FTC Green Guides 及 EU Green Claims Directive：
- 麦秆复合材料（Wheat Straw Composite）必须诚实说明配比：35% 麦秸生物质 + 65% 食品级 PP 粘合剂，不可简称为“纯天然麦秸秆”；
- 硅胶制品必须声明为“100% 食品级/医疗级铂金硅胶，BPA-Free”，禁止含糊使用“Eco-Rubber”；
- 宣传低碳减排必须附带耐科 1.5MW 屋顶光伏发电设备凭证与第三方减排核算数据。
