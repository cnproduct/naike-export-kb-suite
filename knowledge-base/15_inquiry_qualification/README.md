# 15 询盘识别、资格判断与推进 (Inquiry Qualification)

## 询盘 10 维速检核对表 (10-Step Rapid Qualification)
1. **企业真实性核验**: 客户是否使用带有独立域名的企业邮箱（而非通用 Gmail/Hotmail）？
2. **网站与业务匹配**: 客户企业官网是否真实可访问？主营范围是否包含家居/餐厨/母婴/礼品？
3. **目标市场与法规**: 客户是否指明了明确的销售国别或所需的检测合规类型（FDA/LFGB）？
4. **采购品类明确度**: 询价内容是否指向具体产品规格、容量、尺寸，还是泛泛的“Send catalog”？
5. **预计订单规模**: 客户是否给出了预估订量（试单量或整柜柜型 20GP/40HQ）？
6. **定制深度说明**: 是否提到 Logo 印刷方式、包装要求或包装刀版图？
7. **目标交期合理性**: 期望交货期是否在耐科 20-30 天正常生产窗口内？
8. **目标价格预期**: 客户是否有明确的目标采购价格带（Target Price）？
9. **关键联系人职位**: 咨询者是采购经理/创始人，还是初级中介/学生研究员？
10. **跟进意愿与互动**: 首次回复提问后，客户是否在 48 小时内给予实质性反馈？

## L1/L2/L3 三层下钻提问法
- **L1 基础层 (首封回复必核对)**:
  “为了给您核算最精准的阶梯 FOB 价格，请问本次预计的采购数量是多少，以及大货需出运到哪个港口？”
- **L2 规格层 (第2轮跟进下钻)**:
  “请问这款产品是否需要定制专属 Pantone 颜色或丝印/激光 Logo？包装方面是倾向常规环保白盒还是定制零售彩盒？”
- **L3 商业层 (推进打样与签约)**:
  “贵司预计的首批大货上架销售节点是在几月份？我们是否需要在下周初为您安排物理样品顺丰/DHL空运寄送，以便贵司团队进行实际食品接触与跌落测试？”
