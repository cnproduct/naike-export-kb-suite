# 09 ICP 与买家决策委员会 (Buyer Personas)

## 四大核心买家画像矩阵
### 1. 国际大型连锁商超品类买手 (Supermarket Category Buyer)
- **典型机构**: Target, Walmart, Aldi, Metro, Carrefour
- **核心关注**: 审厂资质（Disney/Sedex）、AQL 1.0出货合格率、RRP 货架陈列展盒、大柜拼柜成本控制、准时交货率。
- **首要痛点**: 断货缺货风险、召回风险、包装不符合条码扫描规范。
- **耐科切入点**: 20,000㎡ 规模化产能、自动化注塑线、Disney FAMA 现成验厂资质、可口可乐绿标背书。

### 2. 跨境 DTC 与亚马逊头部品牌主 (Amazon Top Sellers & DTC Founders)
- **典型机构**: Amazon 家居餐厨类目 Top 50 卖家、Shopify 独立站新兴母婴品牌
- **核心关注**: 500-1000 套起订量门槛、专属开模外观专利保护、开箱高质感包装、FBA 包装打标贴标、高精 3D 渲染图包。
- **首要痛点**: 起订量太高资金周转慢、同质化严重被低价内卷、产品差评（如漏油、卡扣易断）。
- **耐科切入点**: 模具车间快速改款、4格密封防漏专利结构、2米跌落抗摔测试证明、免费提供电商主图级渲染图。

### 3. 跨国企业 ESG 礼品与公关采购总监 (Corporate ESG Procurement Manager)
- **典型机构**: 科技巨头、银行金融机构、世界 500 强企业行政与公共关系部门
- **核心关注**: 真实的环保减碳证据、合规发票与社会责任报告、企业定制 Pantone 色与高档礼盒定制。
- **首要痛点**: 漂绿（Greenwashing）公关危机、赠品做工粗糙损伤企业形象、活动交期延误。
- **耐科切入点**: 1.5MW 绿电光伏工厂证明、FSC 环保纸盒包装、48 小时极速出样、激光精细刻蚀企业 Logo。

### 4. 品牌授权商与特许经营商 (Licensed Merchandising Agent)
- **典型机构**: 迪士尼、环球影城、华纳周边授权代工合作商
- **核心关注**: 必须通过 Disney FAMA 验厂且状态活跃、严格防泄密与模具保密保管、色母粒耐光不褪色。
- **首要痛点**: 验厂过期导致授权撤销、生产废品外流引发盗版诉讼。
- **耐科切入点**: 现成 Disney FAMA W128-4829-1、独立监控封闭车间、废件粉碎销毁全流程视频追溯。
