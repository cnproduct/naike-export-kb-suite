# 17 异议、谈判、风险与审批 (Objections & Concessions)

## 10 类高频买家异议应对经典话术
1. **异议 1: “价格比其他供应商贵 10%”**
   - *回应*: “完全理解贵司对成本的严格把控。但耐科报价包含的是经过 Disney FAMA 与可口可乐社会责任验厂的真实大厂质量，采用 100% 纯正食品级初生原料，确保通过德国 LFGB 极苛刻的气味与迁移测试，杜绝欧美海关扣关风险。此外我们包含 AQL 1.0 出货全检，次品率低于 0.3%，实际综合售后损耗远低于小作坊。”
2. **异议 2: “起订量 3,000 套太高，能否 500 套先做？”**
   - *回应*: “如果是定制专色，因为注塑机洗机清膛投料至少需要 500kg 原料以确保整批色差均匀。但为了支持贵司新项目启动，首批我们可以提供两种灵活折中方案：方案 A 使用我们现成的 Morandi 畅销公用色，500 套即可定制贵司 Logo；方案 B 首批按 500 套出货，剩余 2,500 套白坯暂存在我们立体仓库，分两批 3 个月内提完。”
3. **异议 3: “能不能先赊账 (Net 60 / OA)？”**
   - *回应*: “作为通过国际顶级审厂的规范企业，耐科所有流动资金均用于严格采购顶级原生环保料与执行 1.5MW 绿电生产。对于初次合作客户，我们统一严格遵循 30% 定金 + 70% 提单件的国际通用结算规则。当双方稳定合作年提货额超过 50 万美元后，我们可协助向中国出口信用保险公司（SINOSURE）申请专项授信账期。”

## 让步矩阵 (Concession Matrix)
- 严禁单向无条件降价！每一次让步必须换取同等商业利益：
  - 若买家要求降价 3% -> 必须换取订单数量增加 30% 或付款定金提升至 50%；
  - 若买家要求加快交期 7 天 -> 必须换取外包装采用耐科标准现成刀版彩盒。
