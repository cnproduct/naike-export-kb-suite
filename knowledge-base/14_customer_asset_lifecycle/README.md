# 14 客户资产、老客户与关系生命周期 (Customer Lifecycle)

## 客户优先级动态 100 分评分模型
- **采购实力维度 (40分)**: 年采购额 >$100万记40分；$50万-$100万记30分；$10万-$50万记20分；试单级记10分；
- **真实提单记录 (25分)**: 近180天有海关进口提单记25分；近1年有提单记15分；无提单记5分；
- **决策人触达度 (20分)**: 直接对接采购副总裁/创始人记20分；品类买手记15分；助理/中介记5分；
- **企业匹配度 (15分)**: 需求高度契合耐科 5 款主推品记15分；部分契合记10分；偏离主营记0分。

## 客户分层体系与跟进 SLA
- **S 级客户 (90-100分)**: 战略大客户。分配专属资深业务 + 技术厂长，2小时内响应，总经理按季度拜访；
- **A 级客户 (75-89分)**: 重点高潜客户。24小时内提供定制方案与样品，每周至少2次业务推进；
- **B 级客户 (60-74分)**: 标准成长客户。使用自动化邮件序列培育，按标准 MOQ 阶梯报价；
- **C 级客户 (<60分)**: 观察客户。提供自助电子目录，进入公海池等待意图触发。
