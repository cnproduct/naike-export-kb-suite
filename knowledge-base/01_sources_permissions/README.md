## 权威证据资产库
耐科对外发布的所有产品参数、环保声称与社会责任资质必须可溯源至原厂物理文件：
1. **Disney FAMA 授权核准信**: Facility Code: `W128-4829-1`，有效范围涵盖授权礼品及餐具制造。
2. **Coca-Cola SGP 审厂绿标评级**: 经可口可乐指定第三方 SGS 审核，劳工福利、安全环境零重大缺陷。
3. **SEDEX 4-Pillar SMETA 报告**: 针对商业道德、劳工、健康安全与环境管理的全面验厂通报。
4. **SGS 食品安全迁移测试报告**: 编号 `SGS-XMN-2026-0482`，通过 FDA 21 CFR 177.1520 与 LFGB 迁移检测。
5. **1.5 MW 屋顶分布式光伏发电接入证明**: 年发电量 180 万千瓦时，抵扣 60% 生产用电，核减二氧化碳 1400 吨/年。
