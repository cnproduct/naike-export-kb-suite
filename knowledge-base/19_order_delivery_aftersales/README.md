# 19 订单、交付与售后 (Order Delivery & Aftersales SOP)

## 生产到出货 8 大控制节点
1. **合同与 PI 签订**: 双向盖章，明确交货期、FOB 港口、贸易条款（Incoterms 2020）；
2. **大货产前样确认 (Pre-production Sample)**: 客服/业务向客户寄送正式签样，客户签字留底拍照存档；
3. **原料及包材入库检验**: 按照颜色配方与刀版核验，不合格包材当场退回供货商；
4. **中期生产巡检 (During Production Inspection - DUPRO)**: 产量完成 30%-50% 时核对克重、组装配合公差；
5. **成品最终检验 (Final Random Inspection - FRI)**: 按照 AQL 1.0 Major / 2.5 Minor 抽检并生成出厂检验报告；
6. **尾款结算核对**: 客户出具尾款汇款水单，财务多渠道核实入账；
7. **集装箱监装 (Container Loading Supervision)**: 检查货柜无异味、无破损、无漏雨，拍照记录铅封号；
8. **单证提单放行 (Shipping Documents Release)**: 提单正本或电放件（Telex Release）、装箱单、发票、原产地证（CO / Form E）极速交付。

## 售后质量事故分级响应 (P1 / P2 / P3)
- **P1 级重大事故 (批量漏液/材料开裂/海关抽检不合格)**:
  - 1 小时内启动应急小组；
  - 24 小时内联合技术厂长出具鱼骨图 RCA 原因分析；
  - 启动全额召回或免费加急补做空运交付，赔付必须由总经理亲自批准。
- **P2 级中度事故 (个别外箱运输压损/局部印刷轻微偏移)**:
  - 12 小时内响应，核定受损数量；
  - 协商在下一批次翻单中免费补足双倍数量或在尾款中直接抵扣。
- **P3 级轻度瑕疵 (个别辅件卡扣松动/表面极微划痕)**:
  - 24 小时内记录进阿米巴质量改进改善台账，提供操作指导视频。
