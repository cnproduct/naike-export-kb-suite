# 05 制造、研发、质量与供应能力 (Manufacturing & QC)

## 制造车间与产能指标
- **注塑车间**: 36 台高精密全自动伺服节能注塑机（吨位覆盖 120T 至 650T），配机械手自动化取件，日产能 80,000+ 件餐盒/餐具。
- **液态硅胶 (LSR) 车间**: 12 组多腔液态硅胶立式注塑机，配真空脱泡机与二次硫化恒温烘烤隧道炉，日产硅胶吸盘碗/围兜 35,000 套。
- **模具开发中心**: 配备高速 CNC 加工中心、慢走丝线切割及火花机，支持 72 小时出 3D 打印样件，15-20 天交付精密钢模。
- **缝制与包装车间**: 8 条自动装配包装线，配备金属检测仪、重量检重秤、自动封箱打带机。

## AQL 质检控制节点 (IQC -> IPQC -> FQC -> OQC)
耐科严格执行 **MIL-STD-105E / ISO 2859-1: AQL 1.0 (Major) / AQL 2.5 (Minor)** 抽检标准：
1. **IQC 来料检验**: 针对每一批次原料颗粒进行熔指（MFI）、水分测定仪检测，严防色差与杂质混入。
2. **IPQC 过程巡检**: 每 2 小时进行首件比对、产品毛边修剪度、注塑克重偏差检测（公差控制在 ±0.5g）。
3. **关键物理实验室测试**:
   - **气密性防漏测试**: 注入 80°C 试验液体，倾斜 45° 震荡 30 分钟无渗漏；
   - **跌落冲击测试**: 装载模拟物自 2.0 米高度跌落至硬质水泥地，连续 5 次不同角度撞击无破裂；
   - **洗碗机耐用性**: 经商用洗碗机 70°C 高温清洗循环 200 次，外观无起翘变形；
   - **高低温循环**: -20°C 冷冻 24 小时后直接移入 100°C 沸水浴，材料性能稳定。
4. **OQC 出货最终检验**: 严格按照订单核验单证、外箱条码 GS1 可读性、封箱胶带抗拉强度与集装箱装柜防潮干燥剂投放。
