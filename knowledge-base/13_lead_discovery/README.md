# 13 线索发现与客户背调 (Lead Discovery & Profiling)

## 买家快速背调三步走 (L1 -> L2 -> L3)
1. **L1 快速验真 (5分钟初筛)**:
   - 检查联系邮箱域名是否与企业官网一致；
   - 在 LinkedIn 验证发信人是否真实在职；
   - 规则：通过即标记为 Validated Lead，不通过标记为 Suspicious。
2. **L2 商业价值评估 (15分钟定位)**:
   - 检索海关提单数据 (Bill of Lading)，核实近 12 个月是否有从中国（特别是厦门港、宁波港）进口餐厨/日用品记录；
   - 测算买家年进口集装箱量（TEU）与现有供货商份额。
3. **L3 深度攻坚分析 (30分钟产出决策图)**:
   - 穿透采购决策委员会（Buying Committee）：锁定采购总监（Procurement Director）、品类经理（Category Manager）与质量工程师（QA Lead）；
   - 分析买家当前热销产品的差评点（如亚马逊差评反馈卡扣易断或有塑料味），以此作为耐科专利防漏防断结构的破冰切入点。
