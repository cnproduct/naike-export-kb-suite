# 10 买家意图信号与机会评分 (Buyer Intent Signals)

## 意图信号分级与快速响应机制
- **S 级强意图信号 (1 小时内响应)**:
  - 询盘明确附带产品 3D 图纸（STP/STEP 格式）或详细包装刀版图；
  - 询问明确数量（如 "Quote for 1x40HQ container" 或 "10,000 units"）；
  - 提供目标港口（如 CIF Los Angeles / Hamburg）并索要第三方审厂报告。
- **A 级高意图信号 (4 小时内响应)**:
  - 索要特定 SKU 物理样品并主动提供 FedEx/DHL 快递到付账号；
  - 询问特定认证要求（如 "Do you have LFGB test report for wheat straw bento?"）；
  - 询问 1000-3000 套定制 Logo 的梯队报价与交期。
- **B 级中意图信号 (24 小时内响应)**:
  - 索要全套产品电子目录或询问最低起订量；
  - 泛意图询价但未注明采购量与目标国家。
