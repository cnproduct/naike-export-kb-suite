# 20 复盘、指标与持续学习 (Learning & Evolution)

## 赢单与输单复盘机制 (Win/Loss Analysis)
每月耐科各阿米巴销售单元举行一次复盘分析会：
- **赢单归因**: 记录是靠 Disney 验厂资质、光伏绿电证明、快速样品响应还是灵活的 500 套 MOQ 促成成交，沉淀为对应独立站的优势案例；
- **输单归因**: 记录是因为价格过高、交期无法满足、还是缺少特定市场认证（如缺少特定清真 Halal 认证），反馈至研发中心进行模具和原材料升级。

## 知识库成熟度评分 (K0 - K4)
- **K0 (冷启动骨架)**: 仅有目录与待补充字段；
- **K1 (公开事实具备)**: 官网信息、厂区实力、产品参数已校验；
- **K2 (证据链闭合)**: 权威验厂报告、AQL 检测单、光伏发电数据均登记归档；
- **K3 (销售闭环生效)**: 20个独立站内容蓝图就绪，标准报价单与开发信模板投产；
- **K4 (动态演进优化)**: 结合真实海外买家询盘反馈与订单数据实时迭代更新。
*当前耐科知识库成熟度评估: **K3+ (已具备全量独立站前台内容生成与业务闭环能力)**。*
