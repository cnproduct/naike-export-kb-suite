# 16 方案、选型、报价与样品 (Quotation & Samples)

## Good / Better / Best 阶梯报价架构
面对海外高质量买家，禁止只抛出一个干瘪的单价，必须提供具有选择梯度与溢价锚点的 GBB 方案：

### 1. Good 经济起步方案 (Entry Baseline)
- **配置**: 耐科现有公模 + 现货经典配色（如燕麦白/莫兰迪灰） + 单色激光 Logo + 简易环保卡纸封套；
- **MOQ**: 1,000 套；
- **单价参考**: FOB Xiamen $2.15 / 套；
- **定位**: 适合预算受限、追求超高性价比或需要小批量极速试单的跨境新锐卖家。

### 2. Better 推荐主力方案 (Best Value - Recommended)
- **配置**: 耐科高精密专利分格模具 + 定制品牌 Pantone 色 + 模内防刮双色丝印 + 高档覆膜开窗展示彩盒 + 附赠硅胶密封备用圈；
- **MOQ**: 3,000 套；
- **单价参考**: FOB Xiamen $2.45 / 套；
- **定位**: 终端零售与主流品牌的畅销主力款，综合抗摔耐久与货架陈列视觉冲击力。

### 3. Best 顶级旗舰方案 (Premium Customization)
- **配置**: 全套专利防漏结构 + 定制 304 不锈钢内胆 + 600D rPET 专属配套保温午餐包 + 环保金箔烫印礼盒 + 随盒附带 1.5MW 绿电工厂碳足迹减排证书；
- **MOQ**: 5,000 套；
- **单价参考**: FOB Xiamen $3.85 / 套；
- **定位**: 高端百货商超、企业 ESG 高阶迎新礼盒或品牌高端联名限定款。

## 标准打样协议 (Sample Protocol)
- **常规库存样品**: 免费提供 1-2 套（客户承担国际快递到付运费）；
- **定制打样费 (Logo/颜色)**: 收取 $50 - $100 打样工本费，后续正式大单确认后在尾款中 100% 抵扣。
