## 🌟 核心设计理念：统一中台，分化前台

耐科规划的 20 个海外独立站**绝不是换域名、换标题的换皮复制站**。本套系统构建了：
1. **统一中台 (Unified Core)**: 集中管理 PIM 主数据、权威验厂凭证（Disney FAMA / 可口可乐 SGP）、光伏绿电 ESG 证明、AQL 1.0 质检标准、8大不可突破经营红线与阶梯商业规则；
2. **分化前台 (Differentiated Frontends)**: 针对 20 个细分买家任务，自动装配并派生各站点独特的 ICP 定位、主 CTA、35 页首发内容蓝图、技术解构与 Schema.org 结构化数据，确保 100% 契合 Google 搜索实用内容标准。

## 🚀 快速上手指南

### 1. 安装与环境检查
系统基于纯原生 Node.js (v20+)，零重量级外部依赖：
```bash
git clone https://github.com/cnproduct/naike-export-kb-suite.git
cd naike-export-kb-suite
```

### 2. 执行全量合规与架构审计
运行 10 项独立性准则审计，验证 20 站配置、PIM 数据库、21 个模块与 ClaimGuard：
```bash
npm run verify
```

### 3. 多品类独立站内容快速生成 (CLI)

#### 生成产品详情页 (Product Page):
```bash
# 生成 eazylunch 麦秆便当盒 Markdown 规格页
npm run generate:content -- --site eazylunch --type product --sku NK-WS-BENTO-01 --format markdown

# 生成 硅胶婴儿吸盘碗 响应式 HTML 页面 (带 Schema.org JSON-LD 结构化数据)
npm run generate:content -- --site siliconebabyfeedingset --type product --sku NK-SIL-BABY-01 --format html --output ./dist/silicone-baby-plate.html
```

#### 生成工程解决方案页 (Technical Solution Page):
```bash
# 生成 露营餐具站工程解决方案
npm run generate:content -- --site outdoortablewarefactory --type solution --format markdown
```

#### 生成专业采购指南长文 (B2B Sourcing Guide):
```bash
# 生成 欧洲商超采购可持续餐具深度指南
npm run generate:content -- --site sustainabletablewarefactory --type guide --format markdown
```

### 4. 启动可视化 Web 工作室 (Portal)
无需安装任何复杂服务，直接在浏览器中打开 `portal/index.html` 或通过本地 HTTP 服务器运行：
```bash
npm run start:portal
```
浏览器访问 `http://localhost:8080`，即可：
- 🔍 交互式筛选与搜索 20 个独立站战略档案与关键词；
- ⚡ 实时选择任意独立站与品类，一键生成视觉渲染、Markdown 与 Schema.org JSON-LD；
- 🛡️ 查验 Disney FAMA、Coca-Cola SGP 及 1.5MW 光伏 ESG 权威凭据；
- 👥 切换阅读 6 大岗位的业务推进作战手册。

### 5. 启动 Model Context Protocol (MCP) 服务
让 Claude Desktop、Cursor 或 Antigravity 直接操控耐科知识库：
```bash
npm run start:mcp
```
支持的 MCP 工具：
- `list_sites`: 查询 20 站矩阵与关键指标；
- `get_site_details`: 获取特定站点的 ICP、护城河与 35 页蓝图；
- `generate_site_page`: 自动生成产品页、解决方案页或采购指南；
- `audit_claim`: 执行 ClaimGuard 文本合规检查，阻断虚假宣传。

## 🛡️ ClaimGuard 合规防线与反洗绿规则

为规避欧洲及北美严苛的消费者权益法案及不正当竞争风险，系统内置 ClaimGuard 闸门：
1. **反洗绿 (Anti-Greenwashing)**: 严禁将麦秆复合材料（含35%麦秆+65%食品级PP）宣称为 “100% Biodegradable” 或 “Ocean Degradable”，必须明确标注入工业堆肥条件；
2. **知识产权区隔 (Trademark Safeguards)**: 
   - 耐科（Naike / EcoNaike）为晋江市耐克礼品玩具有限公司商号，与美国运动品牌 Nike, Inc. 没有任何关联；
   - Disney 标识必须明确为“合格制造商设施资质（Disney FAMA W128-4829-1）”，不宣称自身为 Disney 商标权利人；
   - 严禁在洞洞鞋配饰中将受保护商标 “Crocs™” 用作品类名，统一规范为 “Clog shoe charms”。
